## 1. コンセプト

- **なめこ栽培キットのような、のんびり放置系ゲーム**を、塩でつくる。
- **教育目的**：遊んでいるうちに、日本の「塩の自給率」が約10%しかないことや、太陽と風でつくる**天日塩**のことが自然とわかる。
- **伝えたいメッセージ**：「日本は塩づくりに向かない」ではなく、**「せっかく海に囲まれた国なのに、もったいない」**。天日塩はいちばん地球にやさしい塩づくりなので、知ってほしい・広めたい。
- **ターゲット**：なめこと同じ。スマホのスキマ時間に遊ぶライト層（大人から子どもまで）。
- **勉強とのバランス**：なめこと同じ。「気がついたら学びになっていた」という作り。

## 3. 主な仕様と、決めた理由

### 遊び方
- 海をタップ → バケツを選ぶ（4・8・12時間）→ てるてる坊主を使うか聞かれる → 砂浜が濡れているあいだ、塩の粒が生まれて育つ。
- 育った塩は、タップかなぞって収穫。まとめて取ると「れんぞくボーナス」。
- 育った塩を放っておくと、しける（なめこの「しなびる」にあたる）。
- 収穫した塩は家族が使う。足りないぶんは輸入塩 → **わが家の自給率**が変わる。

### 天気
- はれ・はれ＋風・くもり・あめ が40秒ごとに変わる（日時から決まるので、だれが遊んでも同じ）。
- 雨の日は育たない。**てるてる坊主**で3分間「てるてる晴れ」にでき、2.5倍の速さで育つ。
- 雨の仕組みはゲームとして残し、伝え方は前向きにする（「雨の日はひと休み。塩のもとは目の前にいくらでもある」）。

### レベルとストーリー
- わが家（第1〜8話）→ まち → けん → くに → おまけ。全20話。
- それぞれのレベルで、伝える内容を分けた：わが家＝天日塩と自給率、まち＝業務用（食品工場・雪どけ）、けん＝工業用（約75%）、くに＝輸入元と、海をきれいに保つこと。

### コレクション
- 塩：わが家12・まち4・けん4・くに4・季節6・ご当地4。ほかに浜のおたから8。
- **季節の塩は、コンプリートの目標から外した**（1年待たないとそろわないため）。
- **ガチャはやらない**（教育ゲームと相性が悪い。コンプガチャは景品表示法で禁止）。

### お知らせ（プッシュ通知）
- 通知するのは3つ：**海水がなくなった／塩がしけそう（5分前）／てるてる坊主が満タン**。
- **アプリを閉じるときに予約し、開いたら取り消す**（遊んでいる最中には通知しない）。
- 「しけそう」の時刻は、ゲームの続きを先回りして計算して決める。
- iPhoneは、ホーム画面に追加したアプリでのみ使える（iOS 16.4以降）。

### みんなの浜
- 全国のプレイヤーの収穫を合計して、「日本人◯人が1年に食べる塩と同じくらい」と表示（1人1日 9.8g で計算）。
- いたずら対策として、1回の送信で足せる数と量に上限をつけている。

## 4. ファクトチェックと権利の確認（2026-10-03）

### 直したこと
| 前 | 後 | 理由 |
|---|---|---|
| 雪塩 | **こなゆき塩** | 「雪塩」は宮古島の会社（株式会社宮古島の雪塩）の商品名 |
| ソーダ灰は塩からつくられている | 塩から**つくることができる** | 天然の鉱石からもつくられるため |
| 天日塩は燃料も電気も**いらない** | **ほとんど**いらない | くみ上げや収穫に機械を少し使うため |
| README「なめこ栽培キット風」 | 「のんびり放置系」 | 他社の商標を使わない・関係があるように見せない |

### 確認して、そのままにしたこと
- **しおじいさん／塩の精**：同じ名前・設定のキャラは見つからず。「塩爺」（塩川正十郎さんの愛称）や「海の精」（塩のブランド）と似ている点は確認したうえで、**今のままにする**と決定。
- **塩自給生活**：同名のゲーム・商品は見つからず。
- **「あーした天気になーれ」**：昔からのはやしことば。童謡「てるてる坊主」の歌詞とは別なので問題なし。
- **ストア公開の前に**：特許庁の J-PlatPat で「塩自給生活」の商標を確認すること。

### 数字の出典
- 塩の需要・自給率：財務省「令和6年度 塩需給実績」（需要 約780万トン、国内産 約81万トン、ソーダ工業用 約75%、業務用 約24%、生活用 約1.5%）
- 食塩摂取量：厚生労働省「令和5年 国民健康・栄養調査」（1日 9.8g）
- 海岸線：国土交通省（約35,293km）
- 輸入元：オーストラリア 約5割、メキシコ 約3割、インド 約2割（業界紙などの報道）
- 塩田の廃止：1971年 塩業近代化臨時措置法、1972年 イオン交換膜法へ全面転換

## 6. 運用の手順

### ゲームを更新する
1. `index.html` などを直す
2. コミットして `git push` → 1〜2分で GitHub Pages に反映
3. 遊べるURL：https://marina-0731.github.io/shio-jikyu-seikatsu/

### サーバー（push-server）を更新する
```bash
cd push-server
npx wrangler deploy
```
- データベースの表を変えたときは `npx wrangler d1 execute shio-jikyu-push --remote --file schema.sql`
- 手元で試すとき：`npx wrangler dev --local --test-scheduled`（`.dev.vars` に秘密鍵が必要）

### 秘密鍵の扱い
- `push-server/vapid-private.json` と `push-server/.dev.vars` は **Git に入れない**（`.gitignore` 済み）。
- Cloudflare には `wrangler secret put VAPID_PRIVATE_JWK` で登録済み。
- 秘密鍵をなくしたら、鍵を作り直してゲーム側の `VAPID_PUBLIC` も差しかえる（通知をオンにしていた人は、オンにし直しが必要）。

### npm がうまく動かないとき
- この Mac では `~/.npm` に書き込めないことがあるため、別の場所をキャッシュに使う：
  `export npm_config_cache=<作業用フォルダ>/npm-cache`
