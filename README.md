# 塩自給生活 🧂

塩を育てて収穫する、なめこ栽培キット風のブラウザゲームです。
遊んでいるうちに、日本の「塩の自給率」や、太陽と風だけでつくる **天日塩（てんぴえん）** のことが自然とわかるようにつくっています。

▶ **遊ぶ：** https://marina-0731.github.io/shio-jikyu-seikatsu/

## あそびかた

- 海をタップすると、砂浜に海水がまかれる。海水が乾くと塩の粒が生まれて、だんだん大きく育つ
- 育った塩はタップかなぞって収穫。まとめてなぞると「れんぞくボーナス」
- 天気で育ち方が変わる。雨の日は育たず、湿気で塩がしけてしまう
- **てるてる坊主** をつるすと、しばらく晴れて塩がぐんぐん育つ（時間がたつとまた作れる）
- 収穫した塩は家族が使う。足りないぶんは輸入塩 → **わが家の自給率** が変わる
- しおじいさんとおばあちゃんのストーリーを進めながら、全12種類の塩を集めよう
