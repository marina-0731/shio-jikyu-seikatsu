# 塩自給生活 🧂

塩を育てて収穫する、のんびり放置系のブラウザゲームです。
遊んでいるうちに、日本の「塩の自給率」や、太陽と風だけでつくる **天日塩（てんぴえん）** のことが自然とわかるようにつくっています。

▶ **遊ぶ：** https://marina-0731.github.io/shio-jikyu-seikatsu/

## あそびかた

- 海をタップして、バケツをえらんで海水をまく（4時間・8時間・12時間）。砂浜が濡れているあいだ、塩の粒が生まれてだんだん大きく育つ
- 育った塩はタップかなぞって収穫。まとめてなぞると「れんぞくボーナス」
- 天気で育ち方が変わる。雨の日は育たず、育った塩を放っておくと しけてしまう
- 海水をまくときに **てるてる坊主** をつるすと、しばらく晴れて塩がぐんぐん育つ（時間がたつとまた作れる）
- 収穫した塩は家族が使う。足りないぶんは輸入塩 → **わが家の自給率** が変わる
- 自給率100%になると、わが家 → まち → けん → くに とレベルアップ。使う塩の量も、浜の広さも大きくなる
- しおじいさんとおばあちゃんのストーリーを進めながら、全34種類の塩（季節限定・ご当地の塩も）と8種類の「浜のおたから」を集めよう（海のゴミ拾いも！）
- 自給率やレアな塩は、画像にしてSNSでシェアできる。毎日「きょうの注目の塩」が変わる
